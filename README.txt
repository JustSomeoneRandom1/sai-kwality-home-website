FILES
- index.html: website content
- style.css: colours, layout and responsive styling
- images/: put your property photographs here

HOW TO ADD YOUR PHOTOS
Copy your own photos into the images folder and use these exact filenames:
- hero-home.jpg             (large main banner photo)
- property-exterior.jpg     (featured property photo)
- living-room.jpg
- bedroom.jpg
- kitchen.jpeg              (your supplied kitchen photograph is already included)
- bathroom.jpg
- dining-area.jpg
- second-bedroom.jpg
- hallway.jpg
- exterior.jpg
- extra-room.jpg

The gallery has nine photo spaces. Missing photos show an “Add photo” placeholder until you add the matching image. You can use other extensions, but update the filename in index.html or style.css to match exactly.

HOW TO VIEW
Open index.html in a web browser. Keep index.html, style.css and the images folder together.
